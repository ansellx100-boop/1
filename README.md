## Ошибка ERROR_OPENAI: network_error

При возникновении ошибки сети (retryable=true) рекомендуем:

1. Проверить доступ в интернет, прокси/фаервол и DNS.
2. Убедиться, что сервис доступен (status.openai.com).
3. Добавить таймауты и повтор запроса с экспоненциальной задержкой.
4. При стриминге повторять весь запрос целиком, не пытаться
   продолжить оборванный поток.

Подробные рекомендации и примеры смотрите в
[`docs/openai-network-error.md`](docs/openai-network-error.md).
